## Como eu trabalho

- **Discovery antes de solução.** Primeiro a dor, o processo atual e os dados disponíveis; depois a ferramenta.
- **Critério de aceite testável ou não é critério.** Observável, binário, verificável sem interpretação.
- **Escopo fechado e assinado.** Requisito ambíguo é retrabalho com data marcada.
- **Auditoria pós-entrega.** Entregue não é aceito; aceito é quando o critério passou.
